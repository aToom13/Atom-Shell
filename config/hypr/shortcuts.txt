  ATOM SHELL + HYPRLAND — KLAVYE KISAYOLLARI
═══════════════════════════════════════════

📱 UYGULAMALAR
  SUPER + W          → Tarayıcı (Zen Browser)
  SUPER + T          → Terminal (kitty)
  SUPER + C          → Editör (Antigravity IDE)
  SUPER + E          → Dosya yöneticisi (Thunar)
  SUPER + SUPER_L    → Uygulama başlatıcı (Launcher)
  CTRL + ALT + V     → Ses ayarları (pavucontrol)

  THINKPAD SİMGELİ TUŞLAR
  F7 (monitör)       → Bağlı ekranların ayarları
  F8 (uçak)          → Uçak modu (donanım işlevi)
  F9                 → Bildirim panelini aç/kapat
  F10 (telefon aç)   → Dikte başlat/bitir; altta durum paneli
  F11 (telefon kapat) → Ekran alanındaki yazıyı panoya kopyala
  F12 (yıldız)       → Kısayol rehberi ve düzenleyici aç/kapat

  SUPER + Tab        → Pencere önizleme (tüm workspace'ler)

🪟 PENCERE YÖNETİMİ
  SUPER + Q          → Pencereyi kapat
  SUPER + F          → Tam ekran
  SUPER + ALT + F    → Borderlı tam ekran (maximized)
  SUPER + ALT + Space → Floating/tile geçişi
  SUPER + P          → Pencereyi sabitle (pin)
  SUPER + ALT + P    → Picture-in-Picture
  SUPER + Z          → Pencereyi sürükle
  SUPER + X          → Pencereyi boyutlandır
  SUPER + yön tuşları → Odağı yöne taşı
  SUPER + SHIFT + yön → Pencereyi yöne taşı
  SUPER + ALT + oklar → Genişliği / yüksekliği değiştir
  CTRL + SUPER + O   → Serbest pencereyi ortala
  CTRL + SUPER + ALT + O → %55 × %70 boyutlandır ve ortala

🔲 WORKSPACE
  SUPER + 0-9        → Workspace'e git
  SUPER + ALT + 0-9 → Pencereyi workspace'e taşı
  SUPER + tekerlek   → Önceki/sonraki workspace
  CTRL + SUPER + ←/→ → Önceki/sonraki workspace

🗂️ GRUP (SEKMELER)
  ALT + TAB          → Çalışma alanındaki sonraki pencere
  SHIFT + ALT + TAB  → Çalışma alanındaki önceki pencere
  SUPER + B          → Grubu oluştur/dağıt
  SUPER + SHIFT + B  → Grup kilidini aç/kapa
  CTRL + ALT + TAB   → Sonraki grup sekmesi
  SUPER + U          → Gruptan çıkar

🔄 SPECIAL WORKSPACE'LER
  SUPER + S          → Special workspace
  SUPER + D          → İletişim (Equibop/Discord)
  SUPER + M          → Müzik (Spotify)
  SUPER + R          → Todo
  CTRL + SHIFT + Esc → Sistem monitörü

📸 EKRAN GÖRÜNTÜSÜ & KAYIT
  PrtScr / SUPER + SHIFT + S → Fotoğraf / video: alan, pencere, uygulama; kayıt kontrolleri
  Yakalama açıkken: SUPER + ALT + oklar → Boyutlandır; SUPER + SHIFT + oklar → Taşı
  SUPER + SHIFT + C  → Renk seçici

🛠️ SİSTEM
  ALT + F4           → Güç menüsü (kapat/yeniden başlat)
  CTRL + ALT + Delete → Güç menüsü
  SUPER + L          → Ekranı kilitle
  SUPER + SHIFT + L  → Uyku
  SUPER + N          → Sidebar
  SUPER + K          → Tüm panelleri göster
  CTRL + ALT + C     → Bildirimleri temizle
  SUPER + V          → Pano geçmişi
  SUPER + .          → Emoji seçici

🎵 MEDYA
  XF86AudioPlay      → Oynat/Duraklat
  XF86AudioNext      → Sonraki parça
  XF86AudioPrev      → Önceki parça
  XF86AudioRaiseVolume → Ses aç
  XF86AudioLowerVolume → Ses kıs
  XF86AudioMute      → Sesi kapat/aç

🔆 PARLAKLIK
  XF86MonBrightnessUp   → Parlaklık arttır
  XF86MonBrightnessDown → Parlaklık azalt

🖱️ FARE
  SUPER + sol tık   → Pencereyi sürükle
  SUPER + sağ tık   → Pencereyi boyutlandır
  SUPER + tekerlek   → Workspace değiştir

👆 TOUCHPAD
  4 parmak → sağa/sola → Workspace değiştir
  3 parmak → yukarı    → Special workspace
  3 parmak → aşağı     → Special workspace aç/kapa
  4 parmak → aşağı     → Uyku

Türkçe Q düzeni: sembol gerektiren atamalar harf / yön tuşlarına taşındı.
SUPER + SHIFT + H: kategori filtreleri, Türkçe arama, kalem ile yerleşik kısayol düzenleme.
CTRL + SUPER + Page Up / Down: önceki / sonraki parça.
